# TCVN & QCVN Informational References

This document lists national technical standards and building codes referenced as domain context for this educational prototype.

> **Disclaimer**: The standards below are referenced for domain background and informational context only. This prototype implements simplified heuristics and does **not** certify compliance with official TCVN/QCVN standards.
